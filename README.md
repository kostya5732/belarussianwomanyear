# Свет Полоцка

Конкурсный сайт о преподобной Ефросинье Полоцкой и соборах Беларуси. Каждая «экспозиция» устроена как музейный зал: слева — картина в золотой раме, справа — сведения (годы, факты, история).

## Разделы
- **Главная** — анимированный заголовок и прорисовывающийся крест.
- **Глава I. Преподобная Ефросинья** — портрет святой и крест Лазаря Богши.
- **Глава II. Летопись жизни** — хронология.
- **Глава III. Соборы и храмы** — Софийский собор и Спасская церковь (Полоцк), Коложская церковь и Фарный костёл (Гродно), Свято-Духов собор (Минск).

## Технологии
Статический HTML/CSS/JS без сборки, шрифты Google Fonts, изображения через Netlify Image CDN (`/.netlify/images`). Картины сгенерированы заранее и лежат в `public/img`.

## Локальный запуск
```bash
netlify dev
```
Сайт откроется на локальном порту; Image CDN эмулируется Netlify CLI.

## Как изменить тексты
Все тексты и факты находятся в `public/data.js`.
